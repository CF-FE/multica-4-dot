# multica-4-dot

将 Multica 接入云端 Dot 的插件项目。Multica 负责执行与运行记录，Task Mailbox 负责持久回执，Dot 负责协调、核对与汇报。当前仅有设计文档，尚无可安装插件或线上服务。

| [插件能力清单](docs/plugin-inventory.md) | MCP、Skills、权限、数据契约与未来目录 |
| [分阶段验证方案](docs/validation-plan.md) | 验收门槛、故障注入、回滚与待决事项 |
