## 集成任务

| 任务与承接方 | 依赖和具体工作 | 可交付的证据 |
|---|---|---|
| G　云端入口，MCP 服务维护方 | A、B、F。提供 Streamable HTTP、工具发现、Dot 专属认证及服务端实例映射；接入经过验证的读取和岗位查询。上线前由实例所有者核发相应的身份与权限 | 同一云端 Dot 经真实登录读到自己的身份，对两个项目取正确原生记录；伪造工作区或对象范围被拒，新增字段保留原有兼容性 |
| H　原生业务写操作，Multica 适配器维护方 | B、C、F。逐项连通项目管理、Issue 创建或复用、分工、静默备注、指定 Run 引导、复审、取消及重跑。项目创建属性与原生关联同事务保存；按动作登记实际执行证据 | 给现任协调员一次真实交办能从同一请求查回卡与 Run；多次重试只建一张卡。离线时展示排队状态；静默操作后原生 Run 数及在途指令均符合预期 |
| I　原件交付与补报，信箱与补报维护方 | D、H。显式交办复用原 job；区分无信箱的内部任务。登记需要补报的 Issue/Run，包括重跑；沿用已有来源、待发台账及回执。处理补报覆盖缺失与旧结果重读 | 正常结果按原版本和摘要由原 Dot 签收；失败 Run 在协调员无回报时有独立异常事实；已运行任务在回程断线恢复后只补同一结果 |
| J　候选版本认证，版本维护方 | E、F、H。对生产基线和候选运行相同测试，逐项复核路由、权限、归属、隐式触发和迁移。对有实质差异的能力进入隔离实例验证，保存候选镜像、源码版本和适配器版本 | 同一报告能看出哪些能力仅通过模拟、哪些经过候选实例实测。公布仍受支持的组合及失效能力。技术维护方可凭原生回执复现评估 |
| K　发布与运维，实例所有者和主会话 | G、H、I、L 与目标版 J。核对 HTTPS、EasyTier、凭据来源、运行身份、备份、只读降级和回退。工作区建立或换任时核对岗位与在途任务 | Dot 端真实闭环与原生证据齐备；在途请求可在停接新写后交还。运行实例、回退镜像、数据库迁移兼容性及物理备份可查 |

G 与 H 可在身份和原生契约稳定后并行。I 需要确切的 Issue/Run 引用，可提前做离线样例。J 的发现和只读检查可与业务开发同步；候选写语义必须等待可验证的写适配器。K 的产物是目标环境的实际回执。

## 主线复核口径

在仓库根目录运行 [mcp/README 中的两组测试](../mcp/README.md)。检查全部新 ADR 的内部链接与证据引用。发行发现看最新正式版、候选与调用异常；原生读契约核实际身份和对象归属；命令测试要覆盖并发和落盘后重启。正式生产检查单独核镜像、真实 Dot 身份及原 Issue/Run/信箱结果。部署后的关闭条件是 G–K 的实际证据可查。

本轮主会话从现有获准的 Multica CLI 只读取得操作者 profile、目标项目、CLOU-21 及其 Run 列表，在内存中把实际响应交给读适配器。身份、项目、Issue、Run 列表与指定 Mike Run 的五项校验均通过。此项证据覆盖当前 `v0.11.0` 的记录结构，使用的是原操作者连接。候选版实机与 Dot 专属账号另验。

2026-11-20 的集成复核通过了服务端 26 项和仓库级 27 项测试。派发账本的修订覆盖跨实例重复 UUID，以及进程重启后从冻结命令恢复已受理请求。上游检查实际发现 `v0.11.1`；只读检查器在回环 HTTP 夹具中通过，EasyTier 私网 HTTP 需要由部署者显式绑定可信私网 IP。四个插件样例 JSON 及 Skill 前置信息通过本地检查。
