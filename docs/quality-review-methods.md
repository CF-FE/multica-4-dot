# 质量小队审核方法索引

质量小队对原卡的验收问题给出可核查的回答。由未参与该版制作或修改的人独审；证据足以回答就回证，有缺陷才进入返工复审。

| 专精 | 审核员回答的问题 | 可交回原卡的一句话 |
|---|---|---|
| 核实交付物 | 审的是哪一版，实物符合哪条标准？ | 我核了这版的这项行为或内容，依据是…… |
| 定位缺陷、验证修复 | 差异怎样复现，改动还影响哪里？ | 在这个输入或位置，预期与实际有此差异；修正点和受影响处复验结果为…… |
| 说明验收范围 | 哪些已通过，哪些确有缺陷，哪些仍未验？ | 已验范围是……；剩余项影响……，按原授权由……接续。 |

## 核实交付物 · CLOU-68

从原卡的候选版本或 Run 找到交付清单，独立取得实物，对照登记值复算与验收有关的字段。核身份可比摘要；核正确性须检查内容或行为。若实际候选已变，先确定旧证据仍覆盖哪些项。需要核 PCM16 WAV 时可直接查[开发小队已有组件及适用格式](development-reuse.md)。

全篇核验中，审核员复算了 13 个最终 MP3 的 SHA-256，逐一匹配原卡。可签认这批音轨的身份和既有签认的覆盖范围。剧情逐字查漏、专项实音听辨、字幕切点等，继续沿各原卡记录。[CLOU-68 质量队长汇总](http://10.207.56.3:3000/cloud-work/issues/01a211a7-8161-75eb-934d-d0157884b429#comment-01a21f88-46da-74e7-b47d-b277859d73fa)

**接手核对动作：**逐项对照人耳签认回执与当前候选的集次、版本、媒介及可用的文件 SHA-256，仅在各项匹配且回执明确覆盖的范围沿用；其余媒介、版本或集次分别核证或保留未验。例如 08-02 v4.3 的同 SHA MP3 获人工终听确认，不代签字幕、封面终看或其他集。[CLOU-67 同版人工终听回执](http://10.207.56.3:3000/cloud-work/issues/01a211a6-a8a1-7a1f-92c8-340597546dde#comment-01a215df-ace9-76d3-a2fa-ce5b8edbc8bd)

## 定位缺陷、验证修复 · CLOU-94

返工时给原执行者一个能复现的差异：在哪个版本、哪个输入或位置、原标准期望什么、实际看到什么。新版本回来，先定位变更，再复验原缺陷及其依赖或相邻内容。能证明其余部分未变时沿用已有有效证据；影响边界查不清时，扩大到能回答原问题的范围。

r3 台本只改动 005 的方位文字。审核员对照 r2、r3 实件和冻结原文，同时核 003–004 接到 005 的叙事关系，确认缺陷已修复。其余话轮沿用已有审核，本轮结论限于台本文本。[CLOU-94 定点复核回证](http://10.207.56.3:3000/cloud-work/issues/01a21fcf-58c6-7b97-8361-4e8b30f062a9#comment-01a21ff0-552e-7a7f-80da-b645992694b8)

## 说明验收范围 · CLOU-75

已证缺陷退给原执行者。对未验项先判断是否影响本次验收：影响的，列出最小补证动作和接续人；原授权允许限定交付的，保留未验项，交指定验收人按该范围核收。

v2 的文件摘要、解码和若干字幕结构检查通过。局部模型听辨出现错误分人等现象，专项听感仍列未验，也没有据此要求重录。公子同意按已交付范围关卡，独立全项通过数未增加。[CLOU-75 正式复审](http://10.207.56.3:3000/cloud-work/issues/01a215da-df8d-76d9-a05f-5677445dc677#comment-01a2170e-95d6-7ef8-84f0-54894f3d6ed1) · [限定关卡与交接](http://10.207.56.3:3000/cloud-work/issues/01a215da-df8d-76d9-a05f-5677445dc677#comment-01a2173b-2222-7085-804b-39b3e580ba1f)
